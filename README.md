# 🎠 Carrossel Responsivo

Projeto de carrossel de imagens dinâmico e responsivo desenvolvido para estudo de animações e transições na web.

## 🚀 Tecnologias Utilizadas

* **HTML5:** Estruturação semântica do projeto.
* **CSS3:** Estilização com variáveis globais (`:root`), Flexbox, CSS Grid, Media Queries e animações avançadas (`@keyframes`).
* **JavaScript:** Lógica de alternância dos slides e controle das classes de animação.

## 📱 Responsividade

O projeto foi adaptado para diferentes tamanhos de tela usando Variáveis CSS dinâmicas:
* **Desktop:** Visualização completa com miniaturas laterais expandidas.
* **Tablets (<= 992px):** Redimensionamento proporcional dos elementos visuais.
* **Celulares (<= 768px e <= 480px):** Ajuste de layout, fontes e proporção das miniaturas para telas menores.
